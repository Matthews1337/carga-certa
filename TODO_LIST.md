# 1 - Corrigir escritas

### O sistema possui escritas como: Descricao, combustivel, caminhao etc... As escritas devem ser corrigidas com a acentuação correta!

# 2 - A página "Painel" deve apresentar ao usuário alguns relatórios: Total do mês(o que entrou - o que saiu financeiramente), com possibilidade de alterar o mês que está sendo mostrado, Total viagens feitas (com possibilidade de alterar o mês que está sendo mostrado), Total km viajados (podendo alterar o mês).

# 3 - O app deve guardar a rota, kilometragem percorrida, data de inicio, data de finalizacao e correlacionar os gastos a esse frete que foi feito pelo usuário, para isso deve ser salvo o caminho percorrido (esta parte terá somente no aplicativo mobile)
